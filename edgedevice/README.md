# 📱 Standalone Edge Device & Mobile Framework

This directory contains the self-contained, lightweight edge & mobile execution framework for Governed Merchant Onboarding Document Verification and Forensics.

## Directory Structure
- `models/` - Quantized INT8 ONNX models for mobile/edge execution
- `agents/` - 4-Agent modular runtime (Extraction, Forensic, Reasoning, Governance)
- `privacy/` - Edge-first PII masking & anonymization engine
- `llm_bridge/` - Governed LLM / SLM explanation bridge
